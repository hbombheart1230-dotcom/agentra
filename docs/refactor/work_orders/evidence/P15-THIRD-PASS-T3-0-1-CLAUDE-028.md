## Task A — analyzer P1 (receiver-type-dependent `replace`)
Cause: `replace` was in the receiver-agnostic pure-method table, so `Path(src).replace(dst)` (a filesystem rename) was classified PURE.
Fix (`scripts/refactor/p158_static_purity_closure.py`, still **ADVISORY**): `replace` is decided only by a *proven* receiver kind — `str` (literal, f-string, `str()` result, `: str` parameter, single-assignment name, str-method chain) → PURE; `pathlib.Path` (direct, aliased `Path as P`, `pathlib.Path`, `pl.Path`, `facade.Path` resolved through the supplied facade module, `/` composition, `with_suffix`/`resolve` chains, `: Path` parameter) → **IMPURE**; anything else → **UNKNOWN**. Names assigned more than once, or bound by loop/with/augmented/unpacking, lose their inferred kind. Receiver-agnostic allowance removed.

Reproducer verdicts (before = analyzer at `a5cffb9`, after = this change):
| Case | before | after |
|---|---|---|
| R1 Path(src).replace(dst) | PURE | IMPURE |
| R2 alias: from pathlib import Path as P; P(src).replace(dst) | PURE | IMPURE |
| R3 unknown receiver obj.replace(dst) | PURE | UNKNOWN |
| S1 str.replace (literal receiver) | PURE | PURE |
| S2 str.replace (str() receiver) | PURE | PURE |

Input-mutating methods (`append`, `update`, `pop`, `setdefault`, `extend`, ... ) — documented in the module: **"pure" means no I/O/clock/env/lock/logging in the call closure, NOT input immutability**. A mutator on a receiver not proven to be a fresh local container (list/dict/set literal, comprehension, `dict()/list()/set()`) is **UNKNOWN** ("input mutation not excluded"); on a proven fresh local it is PURE. Static PURE never approves an extraction; AST moved-body equivalence and behavioral differential remain mandatory independent evidence.
