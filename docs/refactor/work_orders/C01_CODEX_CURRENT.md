**이 C01의 다음 RF·우선순위 갱신은 C03 지팀장만 한다.** B는 매회 최신 C01과 실제 RF 큐를 재조회하되 이 문서를 수정하거나 C03 갱신을 기다려 개발을 멈추지 않는다.

완료는 RF 수용 판정이 아니라 지팀장이 결정한다. 일반 개발은 자동 승인, 보호 실런은 별도 승인.
