**원개발 지시(승인 후):** 저장소 전체 Python AST/import 및 설정/배포/CLI/테스트 문자열 consumer를 **읽기 전용**으로 조사하고, 실계정·네트워크·API 호출 없이 synthetic policy/env에서 ① 현행 text router ② legacy raw wrapper ③ 선택한 primary/fallback 우선순위의 첫 미검증 경계를 테스트한다. 현행 운영 모델과 실제 `.env`·정본 `applied_policy`는 변경하지 않는다. `/tmp/rf050_retirement_boundary.py`를 생성한 뒤 `python /tmp/rf050_retirement_boundary.py`, `python -O /tmp/rf050_retirement_boundary.py`의 marker/실제 exit와 SOURCE_SHA 제출. Linux 외 환경에서는 동일한 세션 격리 임시 경로를 사용하고 실행 경로를 명시한다.

**후보 판정:** 구형 `router.py` 및 정적 모델 카드의 일부가 삭제 가능하다고 *가정하지 않는다*. 하나라도 외부 public/동적/설정/fallback 소비자 불확실성이 있으면 `COMPAT/HOLD`. 새로운 안전한 후보만 정확 함수 단위 `REMOVE_CANDIDATE`로 보고하고 **사용자 별도 승인 전 소스 삭제 금지**. 필요한 교차 RF consumer 이동은 지팀장 Owner 재배정 전 수정 금지. 이후 B 최초 독립 peer, 지팀장 통합 SHA 검증.
