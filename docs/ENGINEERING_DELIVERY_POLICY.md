# D00 — Agentra 공통 안전·권한·증거 원칙

> 각 팀은 **자기 CURRENT부터** 읽는다. 미변경 정본·동일 SHA 증거는 반복 조회하지 않는다. 개발팀: [CURRENT](refactor/work_orders/CURRENT.md) → [D03](refactor/work_orders/D03_DEV_TEAM_RULES.md) 및 D01/D02. PC 런검증팀: [검증 CURRENT](runtime/validation/CURRENT.md) → [D04](runtime/validation/D04_RUNTIME_VALIDATION_RULES.md). 런검증팀에는 A/B RF 업무 규칙을 적용하지 않는다.

## 1. 권한·안전 경계
- `main` 수정·병합은 사용자 명시 승인 전 금지. `integration/p1.5` 통합·RF 최종 DONE은 GPT 지팀장 책임이며, 개발 브랜치 전체 일괄 병합·무승인 강제 push 금지.
- 실계좌 주문/실거래 권한, Broker·Supervisor·Executor·Step5C·UEF 거래 안전 계약·가드·replay/write-safety, CI 오라클·테스트 기대값·allowlist·skip/xfail/waiver는 **명시 승인 없이 변경 금지**. 거부된 오라클 후보 `a0493b60`도 미승인 상태다. 테스트를 GREEN으로 만들기 위한 안전 우회 금지.
- P1.5.0~11 동결 합격 기준과 RF-021 안전 HOLD 유지. 공유 공개 계약·4-HEAD/PR31 합성·미승인 source admission은 지팀장 별도 판단·승인 없이는 통합하지 않는다.
- 모의투자 서버에서의 정상 API·주문 검증은 승인된 **런타임 운용** 범위이며, 안전 코드 수정이나 실계좌 권한 허가와는 별개다. 실계좌 자격 증명·개인 비밀은 코드·Git·검증 보고에 노출하지 않는다.

- **지팀장 직접 처리 의무:** GPT 지팀장은 승인된 소유 경계에서 직접 가능한 코드 수정·표적 테스트·RF 판정·큐 이동·CURRENT/STATUS 갱신·선별 통합을 A/B에 불필요하게 재위임하지 않고 즉시 수행한다. 실행 환경이 없으면 NOT_RUN으로 표시하고 실행 담당을 지정한다. 지팀장 직접 수정분도 별도 독립 검증이 필요하며 안전·CI·DONE 게이트는 그대로 유지한다.

## 1A. 지팀장 자율 진척·DONE 책임
- 사용자의 반복 지적을 기다리지 않고 검증 대기 RF의 완료 가능성을 먼저 판정한다. 성과 기준은 문서 커밋 수가 아닌 **정당한 DONE 증가·선별 통합·차단 해소**다.
- 기존 normal/-O·KEEP·독립 peer 증거를 재사용한다. 인수조건과 소유권이 충족된 RF는 같은 점검 회차에 선별 통합·통합 정확한 SHA의 필수 normal/-O 검증·DONE 판정으로 진행한다.
- 미충족 RF는 정확한 결함/미검증 위험·담당·재개 조건을 해당 RF에만 남기고, 다른 실행 가능 RF를 즉시 진행한다. 장기 차단 RF 하나가 전체 큐를 막지 않게 한다.
- CURRENT는 작업 포인터와 규칙 변경 알림만 유지한다. 세부 판정은 RF, 집계는 STATUS, 실행 증거는 HANDOFF에 두며 중복 감사·반복 테스트·문서-only 빈 커밋을 피한다.
- 독립 검증·소유권·통합 SHA 테스트와 안전 승인 경계는 완화하지 않는다. 미실행은 NOT_RUN으로 기록하고 실행 담당을 지정한다. 증거 없는 DONE은 금지한다.

## 2. 실행·증거의 신뢰성
- 시작 시 대상 저장소·브랜치·정확한 source SHA·설정 및 역할별 권한을 식별하고, 자기 작업장과 기존 상태·데이터를 보존한다. 권한 없는 수정·삭제·배포·통합을 하지 않는다.
- 수행한 명령, 대상 SHA, 실제 출구 코드·테스트·외부 호출·실패 근거를 기록한다. **NOT_RUN/UNKNOWN/BLOCKED를 PASS로 꾸미지 않는다.** 부분 PASS는 전체 PASS가 아니다.
- 실패는 가능하면 같은 조건의 BASE·후보 비교로 기존 문제와 신규 회귀를 구분한다. 반복 검증·중복 문서·불필요한 전체 테스트·빈 커밋을 피한다. 테스트 산출물은 격리하고 성공분 자동 정리·실패분 제한 보존한다.
- 역할별 상세 개발·독립 검증·선별 통합·DONE 게이트는 **D03**, 실운영 동일 조건 PC 런검증·실제 키움 모의투자 증거는 **D04**가 정본이다. 서로의 승인 권한을 대체하지 않는다.

## 지팀장 자율 완료 운영
- 사용자 재촉 없이 매 회차 기존 증거를 재사용해 DONE 가능 RF를 먼저 판정하고, 소유권 승인 범위에서 선별 통합 및 통합 SHA normal/-O 검증까지 직접 추진한다.
- 미충족 RF는 재현 결함 또는 구체적 위험·담당·재개 조건만 해당 RF에 기록하고 다음 실행 가능 RF로 즉시 전환한다. 한 건의 장기 차단이 전체 큐를 막지 않는다.
- 성과는 문서 커밋 수가 아니라 정당한 DONE·통합·차단 해소로 평가한다. CURRENT는 최소 포인터로 유지하고 RF·STATUS·HANDOFF에 상세를 분리한다. 동일 증거 재검토와 불필요한 규칙 추가를 피한다.
- 독립 peer, 승인된 소유권, 통합 SHA 필수 테스트, 실거래 및 안전·오라클 변경 금지 원칙은 생략하지 않는다. 실행 불가 항목은 NOT_RUN으로 보고한다.
